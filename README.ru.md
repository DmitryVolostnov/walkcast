<h1 align="center">WalkCast</h1>

<p align="center"><b>Личный подкаст для вечерней прогулки, который Claude собирает из твоего дня.</b><br>
Каждый вечер Claude читает, чем ты занимался и о чём думал, пишет выпуск минут на 35 из трёх тем,
озвучивает и присылает на телефон. Надеваешь наушники и идёшь гулять с собакой.<br>

## Установка

Нужны Мак, [приложение Claude](https://claude.ai/download) (или Claude Code) и ключ OpenAI для голоса. Вставь в Claude Code:

```
Set up WalkCast for me: clone https://github.com/DmitryVolostnov/walkcast into ~/WalkCast, then read ~/WalkCast/SETUP.md and follow it step by step.
```

Claude спросит имя и пару вещей о тебе, проверит ключ, поставит расписание на 19:00 и даст послушать пробу голоса. На телефоне — iOS-приложение (собирается из `app/` в Xcode) или [веб-плеер](https://dmitryvolostnov.github.io/walkcast/player/): в App Store пока нет.

## Зачем

Почти всё, о чём я думаю за день, проходит через разговоры с Claude: макеты, код, недодуманные идеи, решения на бегу.
Я к ним никогда не возвращаюсь. Прогулка с собакой — мой единственный тихий час, и хотелось, чтобы он был про мою
жизнь, а не про чей-то подкаст. Теперь возвращается за меня Claude.

Я продуктовый дизайнер, и это началось как MVP за один вечер. Сам слушаю каждый день, поэтому делюсь.
Отзывы и идеи — в [Issues](https://github.com/DmitryVolostnov/walkcast/issues).

## Какой получается выпуск
- **Три темы, каждый день новые.** Обычно одна подхватывает то, что ты обсуждал вскользь, и добавляет то, чего в разговоре не было. Остальные — из широкого пула: карьера, ремесло, семья, тело, деньги, философия, история, что-то смешное — или **темы, которые ты выбрал** в приложении накануне.
- **Одна тема — одна понятная мысль.** Текст написан для уха: без списков, сначала контекст, одна история до конца.
- **Иностранный язык по ходу.** Если учишь язык, в каждой теме будет пара живых фраз.
- **Юмор, мнение, честная критика** твоих проектов, когда она по делу.
- **Главы и проигрыш** между темами, можно сразу перейти к любой.

## Приложение
- Выпуски карточками, запоминает позицию, скорость, управление с экрана блокировки.
- Главы с таймкодами.
- Фоновая музыка под голосом: два плейлиста или радио SomaFM, громкость и выключатель.
- **«О чём поговорим завтра?»** — шесть вариантов под каждым выпуском, выбор уходит на Мак через iCloud.

## Как устроено
```
19:00  задача Claude по расписанию
       → pipeline/collect.py   дайджест недавних сессий Claude Code (+ твой выбор с телефона)
       → Claude пишет сценарий по pipeline/PROMPT.md  → episodes/ГГГГ-ММ-ДД.md
       → pipeline/tts.py       OpenAI gpt-4o-mini-tts + проигрыш между темами + главы
                               → iCloud Drive/WalkCast/ГГГГ-ММ-ДД.mp3 + .json
вечер  приложение на айфоне (или веб-плеер) забирает выпуск из iCloud Drive
```
Всё, кроме озвучки, работает локально: Claude читает твои сессии на твоём Маке, в OpenAI уходит только готовый
текст выпуска. Стоимость: примерно $0.5 за выпуск на голос плюс твой лимит Claude.

## Настройка
| Файл | Что |
|---|---|
| `pipeline/PROMPT.md` | Редакционный бриф: длина, структура, тон, правила |
| `pipeline/topics.md` | Пул тем — дописывай свои |
| `pipeline/state/notes.md` | Пожелания («больше про спорт», «меньше про работу»), читаются перед каждым выпуском |
| `pipeline/config.json` | Имя, языки, голос, источники |
| `pipeline/assets/stinger.mp3` | Проигрыш между темами |

**Семейное радио.** В `config.json` есть выключенный второй источник. Направь его на логи Claude или заметки
партнёра (синхронизированные через iCloud) — и выпуск станет для двоих: только общие темы, ничего, что звучит как чтение чужой переписки.
